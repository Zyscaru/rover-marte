# Rover em Marte

Jogo para aprender Java programando um rover em Marte. São 19 missões em 6 setores: sequência, repetição (`for`), métodos (`void`), sensores (`if/else`), laços (`while`) e variáveis. O Java roda direto no navegador e o jogo funciona offline depois de aberto uma vez.

## Como jogar

Escreva comandos como `rover.andar();`, `rover.virarDireita();` e `rover.coletar();` dentro de `void main() { }` para levar o rover até a base, coletando todos os cristais. A partir do setor 4, o mesmo programa é testado em vários terrenos, então é preciso usar os sensores (`rover.frenteLivre()`, `rover.temCristal()`, `rover.naBase()`...). Quanto menos linhas, mais estrelas.

## Instalar no celular

- **Android (Chrome):** menu ⋮ → **Instalar app**.
- **iPhone (Safari):** **Compartilhar** → **Adicionar à Tela de Início**.
